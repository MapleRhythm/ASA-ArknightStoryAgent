# ASA：完整证据自然语言思考对照 v32

241 为唯一规范源。文件名沿用北京时间 2026-09-10，机器回执使用 UTC。
本实验不修改生产代码、模型指针、引用校验或训练标签。

## 结果与边界

同一原生 Qwen3.5-9B、无 LoRA，8 个已有开发问题，每题思考/非思考两条件：

| 条件 | 正常完成 | 总预算耗尽 | 累计生成 token |
|---|---:|---:|---:|
| 非思考 | 8 | 0 | 1423 |
| 思考 | 4 | 4 | 27032 |

两组总输出预算均为 4096，思考与最终答案共用预算；输入完整、上下文 12288。
失败没有被救回或移出分母。以上是完成情况，**不是正确率**。

去掉引用 JSON 后仍有 4/8 思考输出无法完成，说明引用 schema 不能解释全部预算失败。
另一方面，雅拉、诺希斯等题在自然语言思考下可以完成，说明 v31 的失败也不能用于
否定模型所有理解能力。v31 与 v32 更换了 system/输出任务，不是纯 JSON 消融。

v32 保留 question、完整 evidence 和 hypothesis，逐项核验与 v31 相同；
不同于 v30 的 plain 分支，未删除 hypothesis，也未额外注入别名关系。
每对 prompt 只有原生 `enable_thinking` 差异，paired seed 相同、次序交替。

## 内容复核

全部 12 个完成答案已读，14 处原文及 12 处实际输出片段经机器绑定。
这是助手源文复核，不是人工 gold。所有 prose 都没有经过生产引用协议验证。

- 林地：非思考罗列五类群体，包含萨米解释，但未确定问题主体，仍混入无关来源；
  思考失败。
- 夜刀：非思考仍答天灾，并补出火龙加剧天灾；直接相关 E6 明说矿石病。思考失败。
- 初雪：非思考继续混成雪绒并移植茱安娜父亲在车站的经历；思考失败。
- 煌：两组有“花心思、开窍”核心，思考多了未经证明的“她”指代；
  非思考也补了概括性练习预期，不因此认证整答完美。
- 雅拉：非思考把缪尔赛思的毕业生/精灵迷茫经历写给克丽斯腾，并将雅拉写成帮助者。
  思考去掉此错认，且明确不能确认与父母的具体关系；不过照片年代、遗憾与牵挂的
  表述仍有额外延伸，保留这些限制。
- 拉普兰德：思考只保留追杀、独断专行、反扑损失的有据核心，未增加错误动机；
  非思考核心相同但有额外时间与家族背景。这是诊断结果，不是引用验证后的新生产答案。
- 诺希斯：思考保住未来/舞台核心并减少旁枝，但额外写成恩希欧迪斯明确承诺支持
  生命科学和源石解析；可见对话只介绍了这些研究方向，明确承诺本身更宽泛。
- 阿娜特：非思考把预想的观众反应写成原因，还把后来的捏耳朵动作混进最初失语的
  因果；原文先写节奏中断、试图恢复讲话，再写捏耳朵及最初的温暖感受。思考失败。
