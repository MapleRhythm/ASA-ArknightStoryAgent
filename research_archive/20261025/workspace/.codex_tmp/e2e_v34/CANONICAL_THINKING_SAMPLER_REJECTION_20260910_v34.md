## 对照

4 个已反复检查的开发问题：夜刀、初雪、煌、诺希斯。每题两次新生成，
同一原生 Qwen3.5-9B、同一完整引用任务、hypothesis、证据、prompt token IDs、
seed 和总输出预算 4096；两组均开启原生思考。逐题交替执行顺序。

| 参数 | 旧实验配置 | 随权重存档的模型卡通用思考配置 |
|---|---:|---:|
| temperature | 0.1 | 1.0 |
| top_p | 0.8 | 0.95 |
| top_k | -1 | 20 |
| min_p | 0 | 0 |
| presence_penalty | 0 | 1.5 |
| repetition_penalty | 1.05 | 1.0 |

这是多参数配置干预，不能归因到某一个参数。模型卡的一般任务建议不被预先
视作严格逐字引用任务的最优配置；也没有暗中增大输出预算。

## 结果

| 条件 | 正常完成 | 耗尽预算 | 实际展示动作 | 累计输出 token |
|---|---:|---:|---|---:|
| 旧配置 | 1 | 3 | 1 直接回答、3 失败 | 15394 |
| 模型卡配置 | 3 | 1 | 3 弃答、1 失败 | 9174 |

模型卡配置减少了部分预算失败，但没有获得可展示的新答案，并丢失了煌的正对照。
这不是正确率估计，不能将 3/4 完成率说成 75% 正确率。

- 夜刀：旧配置耗尽预算；候选 586 token 完成，找到矿石病/源石核心，
  但引文改写、E3/E6 错绑导致弃答。未自动补字或重绑。
- 初雪：两组都耗尽 4096；采样变化未解决该身份问题。
- 煌：旧配置 3106 token 完成，展示有据核心；候选 3834 token 完成，
  却给出无引文的裸字符串推断，违反已有引用契约，因而弃答。
  不为了保住分数而取消 inferred_facts 的引用要求。
- 诺希斯：旧配置耗尽预算；候选 658 token 完成，但改写或编造三处引文，
  并加入“更强大的文明体系”等延伸，展示仍为弃答。
