# Exx v4 关闭答案校验：50题测试报告

测试日期：2026-09-16（北京时间）

## 结论

使用正式版本 `exx-20260915-v4`（Qwen3.5-4B + Exx v55 SFT adapter），对冻结的
50道历史剧情理解题进行完整链路测试，并在运行时关闭答案校验。最终用户可见答案
的人工复核结果：

| 分类 | 数量 | 占比 |
|---|---:|---:|
| 严格正确 | 15 | 30% |
| 部分正确 | 16 | 32% |
| 错误 | 11 | 22% |
| 拒答 | 8 | 16% |
| 异常 | 0 | 0% |

因此，按“严格正确”口径，正确率为 **15/50 = 30%**；若把部分正确也视为
“至少触及答案核心”，覆盖率为 **31/50 = 62%**。这两者都不应混称为严格正确率。
模型实际回答率为 **42/50 = 84%**（拒答8题）。

## 运行与旁路审计

- 50/50题完成，运行错误：0。
- 109次模型生成调用，59次检索/结论轮次。
- 答案校验旁路事件：59；意外执行答案校验：0。
- 旁路输入与输出结论完全一致：是。
- 每次检索后的20条完整正文均进入提示词：59轮、1180份文档。
- 实际输入token核对：109/109通过；最大输入6633 token。
- 截断或生成预算缩减：0；最大输出预算1536 token。
- finish reason：107 次 `stop`，2 次 `length`。
- 批次耗时：1161.5秒；首题含加载63.8秒，热态题均值22.0秒。

本次只绕过答案验证函数；JSON解析、检索、最多两轮流程，以及模型自身的
`retrieve_more` / `abstain` 仍保留。因此8题“证据不足”是模型自主拒答，
不是校验器造成的拒答。

## 解释

关闭校验后，规则误拒确实消失，但严格正确率仍只有30%。主要剩余问题是：

- 已有证据却主动拒答；
- 漏答多子问；
- 人物、学校或情节场景混淆；
- 将证据中的冲突或无关内容当成事实；
- 少量无依据扩写；
- 个别题出现重复生成并耗尽1536-token预算。

这说明答案校验不是造成4B模型与强模型差距的唯一原因；当前瓶颈仍主要在
4B模型的剧情整合、证据甄别和多子问完整回答能力。
