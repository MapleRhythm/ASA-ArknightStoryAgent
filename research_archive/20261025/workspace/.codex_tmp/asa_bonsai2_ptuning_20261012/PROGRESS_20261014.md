# Fresh GLM full20 accepted-subset P-tuning experiment

## Data and review

- Original Coding Plan annotation batch: 350 processed, 340 accepted, 10
  quarantined; 386 calls. Original `complete=false` is preserved.
- Offline spot review reads all 21 existing GLM review summaries and examines
  21 targets: 11 warning cases plus six additional direct answers and four
  abstain/retrieve cases. Relevant cited chunks are read for answer targets;
  all20 evidence is inspected for the four independent abstain/retrieve cases.
- Fourteen additional rows are conservatively excluded, without rewriting
  any target. Not all exclusions mean the core answer is false; some isolate
  citation overreach, entity ambiguity or action-policy conflicts.
- Reviewed export: train280 / val46; train actions267 answer,8 abstain,5 retrieve;
  val41 answer,4 abstain,1 retrieve.
- Every retained row preserves its full20 evidence, original prompt, target and
  fresh API-response lineage. Original snapshots, exclusion payloads and review
  rationale are embedded with hashes.
- All retained labels have NOT been fully semantically certified. This is not
  human gold, an unseen benchmark, retrieval evaluation or QA accuracy.

## Independent workflow

- `audit_fresh_subset.py`: offline protocol, full-evidence hashes, prompt rebuild,
  teacher receipt equality, split/source/document/question-disjoint checks.
- `train_reviewed.py`: exact audited-subset gate plus longest memory receipt,
  then the unchanged external-encoder trainer.
- `run_reviewed_workflow.py`: detached gate -> train -> raw generation, records
  real child PIDs and terminal failures, refuses existing experiment output.
- Tag: `glm_fresh_reviewed_pt_v1_20261014`, GPU2; other jobs untouched.
- Frozen ternary27B differentiable backend,16 external soft tokens,1epoch,
  LR2e-5,CPU activation offload, no evidence truncation or answer repair.
- NLL evaluation uses all46 validation rows at frozen/initial/trained stages.
- Eight fixed heldout narrative/action cases compare raw frozen/initial/trained
  outputs.1024 generated-token ceiling is explicitly recorded if reached;
  this is an output bound, not truncation of evidence input.
- Backend, old trainer, old run and production release are unchanged.
- Native GGUF soft-embedding injection has not yet been validated; an adapter
  finishing here does not constitute a deployable production release.
