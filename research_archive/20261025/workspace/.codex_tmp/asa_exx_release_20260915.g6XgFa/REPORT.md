# 新Exx链路20题回归与正式默认固定 — 2026-09-15

结论：**新链路已固定为远端正式默认 `exx-20260915-v1`，但本轮全链路
严格正确仅1/20（5%），不满足此前60%的上线质量门槛。**
版本固定是用户授权的工程操作，不等于质量验收合格；未切换独立API服务或推送公共Git/HF版本。

所有题从原始问题运行真实规划、检索、Exx生成及校验，不给gold、旧答案或人工补证。

质量分类互斥：1正确+2部分+17拒答=20。Q14泛泛“证据不足”按旧协议只算
部分/宽松可用，不算严格正确，也不计可回答题错误拒答。

最后一次原始生成内容正确的是Q6、Q8、Q13、Q18；最终交付只保留Q6。
这里只评本次最后输出，不从多轮中挑选最好的草稿；不把思考或旧答案当答案。
语义评分是助手对本次证据及已冻结原文标准的复核，不是独立人工盲审。

同题历史参照：旧SODA/KTO 4B全链路6/20（30%），DeepSeek全链路14/20（70%）。
新Exx包版与旧goldenglow单文件管线的实现、协议和采样不同，因此这是
**两套系统的同题回归，不是只换权重的能力A/B**。不能据此说“新训练让模型能力从30%降到5%”。
历史开发题不是独立泛化集，也不能当线上准确率保证。

## 为什么低

新模型已经不需要复制quote，所有76次输出均可严格解析为JSON对象，未出现
旧quote/evidence_refs/final_answer等目标字段。但JSON正确不代表事实或动作正确。

### 三道明确的校验误拒

- **Q8斯卡蒂**：神经剂来源、听从凯尔希命令两问都正确，所引E5也正确。
  词面检查因“她想知道”“前提条件”“卡蒂时附加”等片段不是源文连续子串而拒绝。
- **Q13霜星**：过去怕伤队友、如今队友都已死两点正确，E1/E2支持。
  词面检查却因“罗德岛交战时”“兄弟姐妹都”等表达拒绝。
- **Q18工人法案**：十五小时和一致的源石防护设备两项齐全，E2支持。
  被“新法案规定感”“新法案规定工”等切词片段拦截。

以上不是E-ID不存在，也不是quote复制错。E-ID模式仍有连续词面检查，
因此去掉手抄引文并没有消除误拒。本轮保留其原规则，不为凑分放宽或重跑。

### 模型自身也有问题

- Q1重复生成四次同一停顿事实，缺第三下/第四下与教官前后认识。
- Q4仍不回答薇卡关系/物品保留缘由。
- Q9混入另一密录的牵手安慰场景。
- Q11编入示威者爆发源石技艺；Q12用辅导报告代替真实改变决定的原因。
- Q19仍把已否决的失窃说法当实际炸厂动机。
- Q20只写藤蔓突破，漏抱住苏茜并制止失控。

所以不能把18个系统拒答全部算成误拒，更不能简单删除校验就声称达到60%。

## 接入修复与失败记录

第一次启动使用旧Exx入口，配置0字符预算被构造器强制改为120，且该入口未读取
`prompt_evidence_require_full_documents`。长证据全部在打包时被拒，模型没有看到
应有证据。该次启动前未充分验证这一配置传递，是接入检查遗漏。
已中止自己的进程，15道已落盘输出及日志保留在 `failed_attempt1`，
不把它当正常阅读评测，也不与后续20题混算。

修复后再冻结版本并运行完整20题：

1. 0真正表示不限字符；完整正文开关从CLI配置传到pipeline。
2. 完整模式保留重排后top20的clean_text/顺序，不替换成长链、不精炼、不pinning。
3. 所有带证据提示逐项核验正文及E编号；缺失即报错，超token窗口不截断。
4. Exx规划和回答都不预填旧左花括号，与其训练目标起点一致。
5. 取消Exx回答阶段硬编码512输出上限，使用配置1536；实际最长输出188，
   本轮并未用尽预算，也未开启思考。

107项相关本地单元测试和3项默认路由测试通过（110项不同测试）。
远端reasoning环境无pytest，未安装新依赖；远端执行了版本哈希与入口核验。
