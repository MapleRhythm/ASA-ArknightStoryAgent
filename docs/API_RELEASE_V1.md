# ASA API 固定版 · api-v1.0.0

日期：2026-09-14。此版本在独立发布分支开发，基于 GitHub 发布主线，
不合并尚未提交的研究实验，不修改远端训练进程、权重、索引或线上服务。

## 固定什么

| 项目 | 发布配置 |
| --- | --- |
| 网页／服务入口 | `bash scripts/run_web_ui.sh` |
| API 配置 | `configs/runtime_api_stable.json` |
| 生成器 | `deepseek-flash`，`thinking.type=disabled` |
| 凭证 | 服务端 `DEEPSEEK_API_KEY`；可用 `--ask-key` 隐藏输入 |
| 本地检索 | CPU，BGE-small-zh-v1.5 + BM25；不加载生成模型或重排器 |
| 候选数 | dense/sparse 120，fusion 80，最终候选 32 |
| 输入证据 | 每次最多前20个完整 chunk，不按字符截断、不替换成摘要 |
| 补证 | 最多2轮；补证 prompt 也保留所选完整 chunk |
| 外围策略 | MiniRAG、CRAG、pinning、MMR、章节补搜、邻接扩展、web 均关闭 |
| 生成协议 | 保留 system/user；移除本地 assistant 预填充；无额外 system 附录 |
| API 重试 | 不自动重试；鉴权、限流、超时、空答、输出耗尽均显式失败 |
| 日志 | 网页请求不落盘保存 prompt/答案；服务端异常日志会遮盖密钥 |

网页只接受 `message` 和最多10条历史消息，不能从浏览器覆盖模型、endpoint、预算、
runtime 文件或密钥。失败的对话不会当作后续模型的事实上下文；当前问题不重复加入历史。
API 每次调用沿用管线对应阶段的输出预算，不再暗中将所有 JSON 请求提高到4096。
DeepSeek 非思考模式的采样约束由服务商决定；此处固定配置不代表能冻结服务商模型权重。

“不截断”是指所选完整检索文本进入 prompt，不保证检索能找齐答案证据，也不意味着
超过服务商上下文上限时会无限扩容。服务商拒绝超长输入或输出未完成时，本版本报告失败，
不会靠裁剪文本、换模型或额外付费重试掩盖问题。

## 安装与启动

1. 按 README 准备 `data/ArknightsGameData`。
2. `bash scripts/setup_cpu_api_no_reranker.sh`，然后 `source .venv-api/bin/activate`。
3. `python scripts/build_retrieval_index.py --device cpu`。
4. `bash scripts/run_web_ui.sh --ask-key`，在隐藏终端提示中输入密钥。
5. 打开 `http://127.0.0.1:7860`，查看「连接与配置」。

已配置环境变量的服务进程可省略 `--ask-key`。变量只由进程读取；本项目不自动加载
`.env` 文件，不把凭证写入 Git。不要把真实密钥放到命令参数、浏览器、测试样例或截图中。

前端不需要 Node 或构建步骤即可运行；Node 仅供开发者执行浏览器回归测试。

## 界面行为

- 示例问题只填入输入框，确认发送后才会调用服务。
- Enter 发送、Shift+Enter 换行；中文输入法确认候选词不触发发送。
- 对话只保存在当前浏览器的 localStorage，最多30个会话；超出时提示先导出／删除，
  不静默删除历史。浏览器不允许存储或容量不足时会提醒导出。
- 左侧可查找会话，右侧可搜索和展开完整检索原文。
- “原文”展示检索结果，不伪称所有段落都进入 prompt 或已被答案引用。
- 复制回答、导出当前对话与原文；删除当前记录需要确认，不影响其他记录。
- 状态条只展示后端真实发送的阶段及耗时，不伪造进度百分比。
- 停止操作中断浏览器请求，服务端通过流式心跳检测断开，终止该请求自己的本地子进程。
  已发送给服务商的请求仍可能执行或计费；不能保证撤销 API 消费。
- 每个服务实例只处理一条推理，忙时返回429，不排入不可见的队列。

## 安全与部署范围

默认只绑定127.0.0.1。这是本地单用户 UI，不含用户认证，不能直接作为公网多用户服务。
对外开放前应由经过配置的反向代理提供认证、TLS、访问控制、限额和审计。
不要将更换绑定地址等同于“可安全公开上线”。

浏览器请求必须同源 JSON；请求体上限128KiB。模型输出及检索内容通过文本节点渲染，
不执行 HTML。静态路由只允许三个前端文件，不公开目录、配置、源码或日志。
请求超时／断开只清理本服务为该请求创建的进程组，不触碰其他实验进程。

## 与历史评测的边界

此前70%来自远端 canonical 管线上的20道开发题，并使用GPU检索／微调重排器。
此分支沿用 GitHub 的模块化实现，默认CPU检索、无重排器；即使生成模型和20条完整
证据策略一致，也不是同一份端到端系统。这里没有发布新的准确率或线上60%保证。

本次测试不调用付费 API：Python 测试覆盖传输、完整证据、参数锁定和异常处理；
浏览器测试使用明确的模拟响应，验证页面、交互、手机布局与安全渲染。
真实检索资源和 API 凭证仍须在部署机器准备；UI 测试通过不等于整题正确率验收。

本次发布检查：

- Python：41项通过，包含HTTP路由、同源／Host校验、子进程超时／取消／关闭、20条全文输入、
  模型参数锁定、失败不重试和凭证遮盖。
- Chromium：10项通过，包含1440×960桌面及390×844手机布局、中文输入法、历史去重、
  原文展开／搜索、复制／导出、失败／重试、停止和删除确认。
- JavaScript语法、Python编译、Shell语法与Git补丁空白检查通过。
- 未重新测问答正确率、未发起付费请求、未部署到远端生产环境。
