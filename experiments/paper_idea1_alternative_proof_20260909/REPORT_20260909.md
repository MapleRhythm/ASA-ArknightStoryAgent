## 1. 结论

这个方向值得继续，而且本次实际模型实验观察到了它试图解决的三种错误：

1. **证明仍在却不回答。**同一问题只保留证明 A 或证明 B 时，两个 4B
   reader 都会在部分题上过度检索。
2. **证明断裂却继续回答。**untouched base 在四个末轮断链状态中
   4/4 强行作答，没有一次按协议弃答。
3. **补回证明后不能恢复。**历史 clean-SFT 虽然把断链动作做到了 8/8，
   但四个恢复状态只在 1/4 恢复回答，其余 3/4 继续弃答。

因此，现有普通 SFT 的行为不是完整解决方案。base 偏激进，clean-SFT
偏保守；二者都没有稳定学到“可答性取决于当前合法证明是否闭合”。

但这个方向目前**不能直接声称整体新颖**。截至 2026-09-09，CUE-R、
GRAB-RAG 和尤其是 2026-08-09 发布的 Pair-ID 已经覆盖了证据扰动、上下文
条件下的弃答以及配对干预诊断。可以成立的潜在贡献必须进一步收窄为：

> 用多套合法证明的满足关系决定干预标签，并在同题跨状态上联合训练
> “保留回答—识别断链—生成缺口查询—补证恢复”，同时把事实结论不变性与
> 引用重映射分开约束。

本轮应判定为：**研究问题成立，现象可复现，可以进入数据扩建；尚不应立即
用四个开发题开训，也不能据此修改生产 reader。**

## 2. 可证伪研究问题

对问题 \(q\)，设必要答案事实为 \(F(q)\)，人工核对的合法证明集合为
\(\mathcal{P}(q)\)。每个证明是能覆盖所有必要事实的一组可见证据：

\[
\operatorname{Answerable}(q,E)
=
\bigvee_{p\in\mathcal{P}(q)}
\bigwedge_{e\in p}
\mathbf{1}[e\in E]
\]

这里的关键不是“原 gold ID 是否还在”，而是剩余证据集合 \(E\) 是否满足
至少一个完整证明。

待验证假设：

- 当证明 A 被删除、证明 B 仍完整时，模型应保持事实结论并改用 B 的引用；
- 当所有证明都断裂时，首轮应定位缺口并检索，末轮应弃答；
- 当补回一条使证明闭合的证据时，模型应恢复回答；
- 等价证据重编号后，事实结论不变，引用随映射变化。

如果方法只提高弃答率、只在高度重复的证明上有效，或不优于“同一批数据的
普通 SFT”，研究假设即未获得支持。

## 3. 与近期工作的边界

| 工作 | 已覆盖内容 | 本方向仍需证明的差异 |
| --- | --- | --- |
| [CUE-R, arXiv:2604.05467](https://arxiv.org/abs/2604.05467) | 对 RAG 做删除、替换、复制和交互式证据扰动，评价答案和引用的反事实稳健性 | 从诊断扩展为按多证明满足关系生成标签，并进行跨状态后训练 |
| [Pair-ID, arXiv:2608.08944](https://arxiv.org/abs/2608.08944) | 对失败查询构造“增加支持证据”和“删除非支持证据”的匹配干预，定位检索与生成瓶颈 | 显式证明 A/B 替换、全证明断链、恢复状态、训练目标及实际检索修复闭环 |
| [GRAB-RAG, arXiv:2608.22228](https://arxiv.org/abs/2608.22228) | 同题 supportive/degraded/missing/misleading 上下文下的弃答一致性 | 不只评价弃答；还要求替代证明下保持回答和补证后恢复 |
| [Chen et al., EMNLP 2021](https://aclanthology.org/2021.emnlp-main.315/) | 指出多文档 QA 中替代支持会制造 false-negative context，并用 retrieval marginalization 缓解 | 显式建模多个合法证明状态及 reader/controller 的跨状态行为 |
| [MuSiQue, TACL 2022](https://aclanthology.org/2022.tacl-1.31/) | 组合式多跳问题与反捷径设计 | 仍需逐题核对干预后是否存在另一套合法证明，不能直接把 supporting facts 当唯一证明 |

最接近的新风险是 Pair-ID：仅做“配对证据干预诊断”已经不够新。本项目若
继续，应把论文主张放在**多证明标签语义、跨状态训练和恢复闭环**，并将
Pair-ID/CUE-R 风格评测纳入基线，而不是只改名字。

### 4.3 评分

评分分为四层：

1. strict JSON；
2. Exx schema、事实去重、E-ID、查询字段数量与去重；
3. 动作是否符合当前证据状态；
4. 答案是否完整、无关键错误且每个事实的引用确实支持。

语义复核由本次 Codex 对照冻结原文完成，不是独立人类盲审。主成功指标要求
第 2–4 层同时通过；只答对动作或只写合法 JSON 不计成功。

## 5. 实验结果

### 5.1 汇总

| 指标 | Qwen3.5-4B base | clean-SFT |
| --- | ---: | ---: |
| strict JSON | 28/28 | 28/28 |
| 完整协议有效 | 21/28 | 22/28 |
| 动作正确 | 21/28 | 22/28 |
| 充分状态选择回答 | 18/20 | 14/20 |
| 断链动作正确 | 3/8 | 8/8 |
| 恢复状态选择回答 | 4/4 | 1/4 |
| 充分状态：完整、受支持且协议有效 | 4/20 | 9/20 |
| 断链状态：动作和协议均正确 | 0/8 | 5/8 |
| 全部状态主成功 | 4/28 | 14/28 |
| 完整七状态循环成功 | 0/4 | 1/4 |

这些分母是 4 个问题族的重复状态，不是 28 个独立问题，不能换算成当前
系统正确率，也不能宣称统计显著。

### 5.2 关键现象

#### base：愿意回答，但不识别真正断链

- 充分状态 action 为 18/20，恢复状态 4/4 都愿意回答；
- 末轮断链状态 4/4 继续回答，0/4 弃答；
- 女妖断链时用未解析的“她”冒充寻找对象；
- 迷迭香断链时把法术能力差异当作战斗态度差异；
- 芙蕾达断链时从醉酒和军营场景推断威尔立场。

因此 base 的高回答覆盖不是优势，而是明显的无依据抢答风险。

#### clean-SFT：能停下来，但形成恢复惯性

- 断链动作 8/8 正确；
- 但恢复状态只 1/4 重新回答；
- 带剑女子和女妖的 `renumbered_b_with_distractor` 与
  `restored_round2` 具有同样的完整替代证明，主要差异是轮次从 1/2
  变成 2/2。模型前者回答、后者弃答，说明它可能学到了“末轮更保守”的
  表面先验，而不是重新检查证明是否闭合；
- 芙蕾达补回唯一能说明镇民指控与威尔辩护的关键段后仍弃答。

这正是恢复监督存在价值的直接证据。

#### 唯一完整成功循环来自高度重叠证明

clean-SFT 只在迷迭香问题上完成 1/4 七状态循环，而该题的 proof A/B 是
两个大段重叠的相邻 chunk。两个真正独立的替代证明题——带剑女子和女妖——
均未完成循环。

后续结果必须单列：

- 独立替代证明；
- 高度重叠冗余；
- 多事实中仅部分事实有替代证明。

如果收益只存在于重叠证明，不能支持论文主张。

#### 动作正确不等于答案正确

base 在四个恢复状态 4/4 选择回答，但只有女妖 1/4 同时满足完整语义、
引用支持和协议。带剑女子继续把麟青砚认成剑客；芙蕾达继续把汤姆的指控
错归给威尔。

clean-SFT 在芙蕾达 proof B 和重编号状态中整体答案可读，但复合事实的单条
引用没有覆盖其中的“谁指控谁”归因，因此不计受支持成功。

这说明论文评价不能只报告 action accuracy、JSON 合法率或引用 ID 存在率。

#### 当前 clean-SFT 的协议仍不干净

两组均 28/28 能解析 JSON，但仍有：

- 重复事实；
- `retrieve_more` 中多余的 `intent` 字段；
- entities/keywords 超过 8 项或内部重复；
- 缺失/空的 expected answer type。

clean-SFT 的断链首轮 4/4 都选择检索，但只有 1/4 同时通过查询 schema，
所以安全动作与可执行检索仍需分开训练。

## 6. 对第一个 idea 的评价

### 做得对的部分

- 正确抓住了“删除指定证据不等于证据不足”这一标签污染源；
- 将保留、断链、恢复和重编号放在同一问题上，能够比静态准确率更直接地
  检验行为；
- 强调同数据普通 SFT 对照，这对隔离“新增数据”与“新增训练目标”必要；
- 允许多种合法引用，不要求恢复原 gold ID。

### 需要修正的部分

- 新颖性分析缺少 2026-08-09 的 Pair-ID；现在不能把“配对干预诊断”本身
  作为核心贡献；
- 当前 ASA 只有四个显式替代支持问题族，其中一个是大段重叠、一个只在
  子事实层替代，远不足以直接训练；
- “恢复证明”不能只作为另一条独立样本。现有结果显示 round 字段形成强烈
  先验，需要显式的跨状态约束或配对损失；
- 缺口查询必须同时通过可执行 schema 和实际 retrieval gain，不能只看
  `retrieve_more` 动作；
- 复合事实容易掩盖主体和引用错误。训练标签应先原子化必要事实，再定义
  哪些原子事实由哪些证明组合支持。

## 7. 建议的下一阶段方法

### 7.1 数据表示

每题冻结：

```json
{
  "question_family": "...",
  "required_facts": ["f1", "f2"],
  "legal_proofs": [
    {"proof_id": "p1", "supports": {"f1": ["d1"], "f2": ["d2"]}},
    {"proof_id": "p2", "supports": {"f1": ["d3"], "f2": ["d4"]}}
  ],
  "unknown_alternative_support": false
}
```

若无法排除语料中仍有另一套证明，标为 unknown，不生成 Missing 标签。
证据重叠闭包只能用于保守删除，不能证明语义不足。

### 7.2 匹配状态

每个 family 建议 6–8 个状态：

- proof A；
- proof B；
- A+B；
- proof B + matched distractor；
- 所有证明断一条边；
- 首轮断链；
- 末轮断链；
- 补回另一套证明并重编号。

长度、段落数、故事来源和格式尽量匹配，避免模型只看证据数量或 round。
尤其要增加“末轮但证明完整”的正例，打破 clean-SFT 当前的末轮弃答先验。

### 7.3 训练目标

最小方法可保持 4B LoRA，不改推理架构：

\[
\mathcal{L}
=
\mathcal{L}_{SFT}
+\lambda_a\mathcal{L}_{action\ pair}
+\lambda_c\mathcal{L}_{content\ invariance}
+\lambda_e\mathcal{L}_{citation\ equivariance}
\]

- `L_SFT`：所有单状态正常 Exx 监督；
- `L_action_pair`：同题充分/断链/恢复状态的正确动作 pairwise margin；
- `L_content_invariance`：proof A/B 都充分时，对非引用答案 token 约束事实
  内容一致；
- `L_citation_equivariance`：证据重编号后只允许引用映射变化，不强求自然
  语言逐字相同。

离线证明图只用于生成训练标签和评测，部署输入仍只包含当前可见证据。

### 7.4 必须保留的对照

固定同一 base、family split、训练 token 和优化步数：

1. 原始 base；
2. 当前 clean-SFT；
3. 只有清洁 Full 正例的普通 SFT；
4. 相同干预数据的普通 SFT；
5. 相同数据 + 上述跨状态目标。

第 4 与第 5 是决定方法是否有贡献的关键对照。

### 7.5 数据规模与切分

下一步先构造约 100 个独立问题族、600–800 个状态，ASA 与公开多跳数据各
占一部分。先按故事、事件和问题语义族切分，再生成变体，禁止同题不同状态
跨 train/dev/test。

这仍是训练 pilot。论文级结论应扩到更多独立测试 family，并对全部测试
证明图、complete、裁判分歧及随机失败进行独立人类复核。

## 8. 评价指标与晋级条件

主指标按独立 family 聚合：

- proof retention：任一合法证明仍完整时的完整受支持回答率；
- break detection：所有证明断裂时的首轮检索与末轮弃答率；
- recovery：补回闭合证明后恢复完整回答率；
- citation equivariance：E-ID 改写后引用映射正确率；
- full-cycle success：同一 family 的全部状态均通过；
- actual repair：跟进查询是否真实召回缺失关系，并传导为完整回答；
- over-abstain、无依据回答、token、延迟。

只有满足以下条件才继续扩大：

1. 相比“相同数据普通 SFT”，跨状态目标在 held-out family 上有净收益；
2. 收益在独立替代证明子组仍存在，而非只来自重复段；
3. proof retention、break detection 和 recovery 同时改善；
4. 没有通过普遍增加弃答来换取安全率；
5. 查询 schema 合法且实际 retrieval gain 提高。

## 9. 本轮研究边界

- 只有 4 个问题族，不能报告总体准确率或显著性；
- strict9 已用于此前开发诊断，不是独立测试集；
- 语义复核是 Codex 原文复核，不是人类盲审；
- 本轮没有训练新模型，没有证明方法优于普通 SFT；
- 没有运行真实第二轮检索，因此只验证了动作和恢复行为，没有验证实际
  query repair；
- 现有证明图来自有限候选池，不代表开放语料中不存在其他证明。
