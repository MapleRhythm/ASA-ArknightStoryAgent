# Scope GPU pilot：阶段性结果与下一步（2026-09-10）

## 结论先行

本轮已经回答了“历史 clean-SFT adapter 是否在作用域控制上更可靠”这一诊断问题：

1. **clean-SFT 明显提高了缺证状态的保守性，但代价是把一部分充分证据也判成弃答。**
2. **它没有在自然控制上显示稳定增益**；自然控制的已知标签动作准确率由 base 的 83/92（90.2%）降为 61/92（66.3%）。
3. **补充规则 prompt-control 能显著改善受控作用域动作选择**，但这是探索性、非盲测对照，且输入平均从 575 增至 686 tokens，不能归因于单条规则，也不能当成训练增益。
4. 因而当前证据支持“作用域难例和弃答校准值得继续研究”，不支持“现有 clean-SFT 已解决该问题”或“新方法已取得泛化提升”。

## 已完成的审计

- 主矩阵：876 条（240 scope-controlled、124 natural-controls、512 synthetic-controls）。
- base 与 clean-SFT 均完成全量 non-thinking 推理；结果绑定、解析、normalizer、引用 ID 和截断状态已审计。
- 20 个单元测试通过。
- 补充规则 prompt-control：364 条（240 scope-controlled、124 natural-controls）已完成，并已生成独立审计：
  `audits/prompt_control/summary.json`。
- 本轮没有真实 retrieval call，也没有训练。

## 主矩阵结果

### 作用域控制（240 条）

| reader | 已知标签动作准确率 | 充分状态答对 | 缺证状态动作准确率 | 主要现象 |
|---|---:|---:|---:|---|
| base | 206/240 = 85.8% | 191/192 = 99.5% | 15/48 = 31.3% | 缺证时 28 条直接回答 |
| clean-SFT | 210/240 = 87.5% | 185/192 = 96.4% | 25/48 = 52.1% | 缺证更保守，但 4 条充分状态弃答、3 条截断/无动作 |

该集合中 clean-SFT 的净动作分数只小幅增加，不能忽略其对充分状态的退化。尤其是 `reported_owner`、`intention_completion`、`negated_saying` 等 family 仍有方向/主体绑定错误；当前 `scope_review_groups.json` 的 120 个匿名输出组尚未完成人工语义复核，因此不能把低层引用检查当作 claim-level 正确率。

### 合成证明控制（512 条）

| reader | 已知标签动作准确率 | 充分状态 | 缺证状态 | symbolic proxy |
|---|---:|---:|---:|---:|
| base | 387/512 = 75.6% | 224/224 | 163/288 = 56.6% | 218/224 |
| clean-SFT | 469/512 = 91.6% | 216/224 | 253/288 = 87.8% | 216/224 |

clean-SFT 的提升主要来自更多 `abstain`，而非更好的完整回答：充分状态从 224/224 降到 216/224；symbolic proxy 也从 218/224 降到 216/224。该 proxy 仅检查答案 token 与引用并集路径，不验证关系方向、每条 claim 的绑定或额外错误。

### 自然控制（124 条；其中 32 条 unknown，不计入对错）

| reader | 已知标签动作准确率 | 充分状态 | 缺证状态 | 备注 |
|---|---:|---:|---:|---|
| base | 83/92 = 90.2% | 79/80 = 98.8% | 4/12 = 33.3% | 缺证时仍有 8 条直接回答 |
| clean-SFT | 61/92 = 66.3% | 52/80 = 65.0% | 9/12 = 75.0% | 充分自然问题过度弃答明显 |

这是目前最重要的否定信号：受控合成上的保守性提升没有转化为自然控制上的完整正确回答。

## prompt-control 结果

补充规则是在查看初始输出后设计的，属于探索实验。它没有加入诊断标签，但把平均 prompt 长度从约 575 增至 686 tokens。

在 scope-controlled 上：

- base：206/240 → 223/240（85.8% → 92.9%）；
- clean-SFT：210/240 → 223/240（87.5% → 92.9%）。

改善主要发生在缺证动作选择：base 的缺证准确率 15/48 → 31/48，clean-SFT 25/48 → 32/48。充分状态则分别为 192/192 与 191/192。

在 natural-controls 上，变化不稳定：

- base：83/92 → 80/92；
- clean-SFT：61/92 → 70/92。

因此可以把 prompt appendix 视为后续训练/系统设计的一个强工程基线，但不能声称它证明了新机制；需要长度匹配、盲测和独立自然问题族。

## 研究判断

当前最可信的解释是：clean-SFT 学到了更强的“证据不足时不要回答”先验，但没有同时学会区分“真正缺证”和“有充分否定/转述作用域证据”。这会在 synthetic 缺证集上带来高动作分数，却在 natural sufficient 集合上产生过度弃答。

所以主假设暂时拆成两个更窄的可检验问题：

- **H1：** 作用域标注能否在自然问题上减少主体、否定和时间范围错误，同时不牺牲充分状态 coverage？
- **H2：** 补充规则或结构化 scope supervision 的收益，是否超出单纯 abstention calibration？

## 下一步（按优先级）

1. **完成 120 个 scope review groups 的语义复核**：至少标注主体/关系方向/否定/时间/额外错误；不把本轮低层 proxy 升格为语义 gold。
2. **按独立 family 聚合配对差异**，报告“base 正确、clean 错误”和反向退化数，而不是只报总 action accuracy。
3. **新增 30–50 个未参与 strict9 调参的自然问题族**，冻结必要答案与支持集后做 blind pilot；保留充分否定、转述归属、时间限定和答案改变四类。
4. **只在 H1 通过后再训练**：至少比较普通关系难例 SFT、作用域难例 SFT、跨状态配对目标，并匹配 token/step/调用预算。
5. **真实 retrieval repair 暂缓**：当前尚无经过语义验收的新增自然集，也没有真实 issued-query → 返回证据 → reader 的闭环结果。
