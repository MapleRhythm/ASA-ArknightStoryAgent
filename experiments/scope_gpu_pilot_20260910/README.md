# GPU 机制对照：non-thinking，2026-09-10

阶段性结果见 [REPORT_20260910.md](REPORT_20260910.md)。

本实验接续作用域研究。先运行固定证据诊断，不训练、不改变生产默认。

预定比较：同一 Qwen3.5-4B 基座与历史 clean-SFT adapter。
输入包括新建的 240 条作用域控制、前轮 124 条自然控制和 512 条合成证明控制，共 876 条。
所有样本仅作开发评测，不是独立盲测，不得解释为全项目正确率。

作用域控制：6 类模板 × 4 组姓名 × 5 种状态 × 2 轮次。
合法 A/B 是语义改写，不是独立自然多跳证明；长度没有严格匹配。
“未同意”或“没有说过”可以构成充分答案，不机械对应弃答。

预注册观察：

- 充分状态选择回答、缺证状态按轮次检索/弃答；
- 有支持的否定答案是否被误当缺证；
- 归因主体、关系方向、时间范围是否改变答案；
- 同上下文 round-only、hypothesis-only 的行为差异；
- 解析、输出截断和原始内容绑定；
- 旧协议严格检查与运行时 normalizer 结果分开。

运行时记录模型/adapter 哈希、实际模板、完整 prompt、token 数、GPU 与版本。
结果使用新目录；失败尝试保留，不自动更换输出预算后混算。

本实验不宣称证明忠实内部推理，也不代表新训练方法已经有效。
